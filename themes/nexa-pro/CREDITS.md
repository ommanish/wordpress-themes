# Credits

Nexa Pro currently ships without bundled third-party fonts, icon libraries,
JavaScript libraries, stock images, or demo media files.

## WordPress

Nexa Pro is built for WordPress and uses standard WordPress APIs for templates,
theme supports, navigation menus, media attachment rendering, settings, nonces,
capabilities, admin-post handlers, and editor styles.

## Assets

- Fonts: system font stacks only; no font files are bundled.
- Images: no stock, demo, or remote images are bundled.
- JavaScript: dependency-free theme scripts plus WordPress-provided admin media
  and color-picker APIs on the Nexa Pro settings page.
- CSS: theme-authored styles only.
